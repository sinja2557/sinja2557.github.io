1. 지원 동기
[막혀 있던 문제가 풀리는 순간, 개발자의 길을 확신했습니다]
사용자가 즐길 기능을 직접 만들고, 그 과정에서 마주친 난제를 끝내 풀어냈을 때의 쾌감이 저를 개발자의 길로 이끌었습니다.
마인크래프트 서버에 더블 점프 기능을 넣으려 했을 때, 서버 API에는 공중에서 점프 키를 다시 누르는 동작을 감지하는 기능이 없었습니다. 공식 문서와 커뮤니티 사례를 찾아보며 여러 방식을 시험했고, 마침내 실마리를 찾았습니다. 점프하는 순간 비행 권한을 잠시 열어 두면, 공중에서 점프 키를 한 번 더 누를 때 비행 전환 신호가 발생한다는 점이었습니다. 저는 이 신호를 가로채 비행 대신 도약으로 바꾸고, 착지하면 권한을 다시 닫도록 구현했습니다.
캐릭터가 의도한 궤적으로 솟구쳐 오르던 그 순간의 짜릿함은 지금도 선명합니다. 그것은 단순히 기능이 동작했다는 안도감이 아니었습니다. 닫혀 있던 길을 스스로 열어 냈다는 확신과, 이 기능을 즐길 사용자를 떠올리는 설렘이 한꺼번에 밀려온 감정이었습니다. 이후 5초 쿨타임과 착지 시 1.5초 낙하 피해 면역을 더해, 동작을 넘어 사용감까지 다듬었습니다.
즐거운 경험을 설계하는 일과, 그 이면의 난제를 끈질기게 풀어내는 일. 제가 가장 좋아하는 이 두 가지를 마음껏 펼칠 수 있는 곳이 [회사명]이라 믿기에 지원했습니다.

2. 성장 과정
[한 줄의 해답을 찾기 위해 끝까지 파고듭니다]
저는 원인이 보이지 않는 문제 앞에서도 물러서지 않고, 한 단계씩 좁혀 가며 해결하는 과정을 통해 성장했습니다.
캡스톤디자인 2에서 자동 디퓨저의 기기 소프트웨어를 맡았을 때, 블루투스 자동 페어링 프로그램이 라즈베리 파이 부팅 시에만 실행되지 않는 문제를 겪었습니다. 직접 실행하면 아무 문제가 없었기에 원인을 찾기가 더 까다로웠습니다. 부팅 과정을 하나씩 점검한 끝에, 시스템이 준비되기 전에 프로그램이 먼저 실행된다는 점을 발견했고, 실행 시점을 15초 늦춰 문제를 해결했습니다.
결과적으로는 한 줄의 수정이었지만, 그 한 줄에 닿기까지의 과정이 저를 개발자로 단련시켰습니다. 저는 이 해결 과정을 설치 문서에 그대로 기록해, 팀원이 같은 문제로 시간을 잃지 않도록 했습니다.

3. 성격의 장단점
[맡은 기능은 끝까지 완성하고, 과정은 기록으로 남깁니다]
저의 강점은 맡은 일을 끝까지 완성하고, 그 과정을 기록해 함께 일하는 사람과 공유하는 것입니다. 디퓨저 프로젝트에서는 와이파이 연결, Firebase 상태 동기화, 부팅 시 자동 실행, 전원 버튼 처리까지 기기 소프트웨어 전반을 구현했습니다. 동시에 필요한 라이브러리 설치 명령어와 설정 방법을 문서로 정리해, 팀원 누구나 같은 개발 환경을 만들 수 있게 했습니다. 개인 프로젝트에서도 참고한 공식 문서와 자료를 README에 주제별로 정리해 두고 필요할 때마다 다시 찾아봅니다.
반면 세부 구현에 시간을 많이 쓰는 편입니다. 이를 보완하기 위해 작업 전에 구현할 기능 목록을 먼저 정리하고, 지금 구현 가능한 항목부터 처리합니다. 서버 플러그인을 개발할 때도 할 일 목록을 우선순위별로 나눠 관리하며 완성도와 속도의 균형을 맞추고 있습니다.

4. 직무 역량과 경험
[서비스 기능 설계부터 서버 구조와 보안까지 직접 다뤘습니다]
저는 서버 기능을 직접 설계하고 구현한 경험, 그리고 이를 뒷받침하는 시스템과 보안 지식을 갖추고 있습니다.
첫째, Java로 약 8,700줄 규모의 마인크래프트 서버 플러그인 2종을 개발했습니다. 화폐와 수표, 경매장, 단계별 버프를 주는 직업, 슬롯머신 등 서버 경제와 콘텐츠를 아우르는 19개 명령어를 만들었고, 커스텀 메뉴 화면과 스코어보드, 파일 기반 데이터 저장 구조를 설계했습니다. 경매장에는 등록 쿨타임을 두어 반복 등록을 막았고, 사용자가 접속을 종료하면 상태 데이터를 정리해 메모리가 쌓이지 않도록 처리했습니다. 매번 파일을 읽고 쓰는 구조의 최적화와, 거래 사기를 막는 1대1 교환 시스템은 다음 과제로 정리해 두었습니다.
둘째, 시스템프로그래밍 수업에서 25회차 실습 동안 프로세스, 스레드와 뮤텍스, 메시지 큐, 공유 메모리, TCP 소켓 통신을 C로 직접 구현했습니다. 여러 사용자가 동시에 접속하는 서버가 어떻게 자원을 나누고 통신하는지 이해하는 바탕이 되었습니다.
셋째, 현재 경기인력개발원 Microsoft 사이버보안 과정에서 버튼 하나로 Azure 실습 환경을 배포하는 웹 포털을 개인 프로젝트로 개발했습니다. 가상 네트워크, VM, 데이터베이스 등 10종의 리소스를 템플릿으로 정의했고, VM의 공인 IP를 없애고 데이터베이스를 내부망에서만 접근하도록 제한해 외부 노출 지점을 줄였습니다. 이 경험으로 기능을 만들 때 공격받을 수 있는 지점까지 함께 고려하는 시각을 길렀습니다.

5. 입사 후 포부
[사용자의 경험과 서비스의 안정을 함께 책임지는 개발자가 되겠습니다]
입사 후에는 먼저 팀의 코드 구조와 개발 방식을 빠르게 익혀, 맡은 기능을 일정 안에 안정적으로 구현하는 개발자가 되겠습니다. 모르는 부분은 문서와 코드를 먼저 찾아본 뒤 질문하고, 해결한 내용은 기록으로 남겨 팀의 시간을 아끼겠습니다.
장기적으로는 사용자가 느끼는 경험과 서비스의 안정성을 함께 책임지는 개발자로 성장하겠습니다. 서버 플러그인을 만들며 배운 기능 설계 경험과 사이버보안 과정에서 익힌 보안 지식을 바탕으로, 안전하고 신뢰받는 서비스를 만드는 데 기여하겠습니다.
