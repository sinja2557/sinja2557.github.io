경기인력개발원 Microsoft 사이버보안 8회차, 개인 프로젝트

Azure 인프라 요청 포털

버튼 하나로 Azure 실습 환경을 자동 배포하는 서버리스 웹 포털을 만들었습니다.

  • JavaScript
  • Vite
  • MSAL
  • ARM Template
  • Azure Static Web Apps
  • GitHub Actions
소스 코드
  • Entra ID로 로그인한 사용자의 권한으로 ARM REST API를 직접 호출해, 백엔드 서버 없이 동작하도록 설계했습니다.
  • ARM 템플릿 하나에 가상 네트워크(서브넷 3개), VM, PostgreSQL, App Service 등 10종의 리소스를 정의했습니다.
  • VM의 공인 IP를 없애고 DB를 VNet 내부에서만 접근하도록 제한했으며, 배포 직후 비밀번호 입력값을 지워 노출 지점을 줄였습니다.
  • 10초 간격으로 배포 상태를 조회해 리소스별 진행 상황과 실패 원인을 화면에 표시했습니다.
  • Ubuntu, Windows Server, Windows 11 중 선택할 수 있게 하고, 모든 VM에 보안 부팅과 vTPM을 적용했습니다.

Microsoft 사이버보안 8회차, 개인 프로젝트

네트워크 계산기

  • HTML
  • CSS
  • JavaScript

네트워크 학습에 필요한 계산을 한 화면에서 처리하는 웹 도구를 만들었습니다.

  • IP와 CIDR를 입력하면 네트워크 주소, 브로드캐스트, 호스트 범위, 와일드카드, 클래스를 계산합니다.
  • 두 IP가 같은 네트워크에 속하는지 판별하고, 2진수 변환과 연산 과정을 단계별로 보여 줍니다.
  • 외부 라이브러리 없이 비트 연산을 직접 구현해 약 1,270줄의 JavaScript로 완성했습니다.

캡스톤디자인 2, 팀 프로젝트

자동 디퓨저

담당: 기기 소프트웨어(SW) 개발

  • Python
  • Raspberry Pi
  • Bluetooth
  • Firebase
  • BeautifulSoup

사용자가 설정한 시간에 맞춰 향을 자동으로 바꾸는 IoT 디퓨저의 기기 소프트웨어를 개발했습니다.

  • 블루투스로 스마트폰에서 와이파이 정보를 받아 자동 연결하고, 연결에 실패하면 설정을 초기화해 다시 받도록 구현했습니다.
  • Firebase Realtime Database로 기기 전원 상태와 사용자 설정을 실시간으로 동기화했습니다.
  • 날씨 정보를 크롤링해 서버에 올리고, 부팅 시 필요한 프로그램이 자동 실행되도록 구성했습니다.
시연 영상 소스 코드

개인 프로젝트

마인크래프트 서버 플러그인

  • Java 23
  • Spigot API 1.21
  • Maven
  • IntelliJ IDEA

약 8,700줄 규모의 서버 플러그인 2종을 직접 설계하고 구현했습니다.

  • Playground: 화폐와 수표, 경매장, 단계별 직업 버프, 슬롯머신, 홈 이동 등 19개 명령어를 만들었습니다.
  • Playground: 커스텀 GUI 메뉴와 스코어보드를 구성하고, 플레이어 데이터를 YAML 파일로 저장했습니다.
  • xRPGx: 더블 점프 이동기에 쿨타임 표시, 낙하 피해 면역, 사용자와 관리자 권한 분리를 적용했습니다.
  • xRPGx: 플레이어가 접속을 종료하면 상태 데이터를 정리해 메모리가 쌓이지 않도록 처리했습니다.

캡스톤디자인 1, 팀 프로젝트

날씨 기반 코디 추천 웹

담당: 메인 페이지 구현

  • React
  • JavaScript
  • OpenWeatherMap API

위치 기반 날씨에 맞춰 옷차림과 음식을 추천하는 웹페이지에서 첫 메인 페이지를 구현했습니다.

  • 위치 권한으로 받은 좌표로 OpenWeatherMap API를 호출해 현재 날씨, 기온, 강수 확률, 미세먼지를 메인 화면에 표시했습니다.
  • 남성, 여성, 공용 코디와 음식 추천 페이지로 이동하는 메인 메뉴를 구성했습니다.
  • GitHub Pages로 배포해 누구나 바로 사용할 수 있게 했습니다.
